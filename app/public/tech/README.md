# Technology logo sources

Local SVGs from Simple Icons 16.32.0. Paths and brand colors are unchanged. Simple Icons is CC0; individual brand guidelines still apply.

React Native uses the React mark; Apollo Client and Apollo Server use the Apollo GraphQL mark. Mongoloquent uses the PNG logo from its official site. RESTful API and bcryptjs use custom functional symbols (request/response and password hashing), not official brand logos. Indonesia and English use typographic language identifiers, not country flags. These four supplemental SVGs were drawn for this portfolio; Simple Icons attribution applies only to the assets listed below from that collection.
